# User Feedback Summary (Phase 7)

A 15-minute session with 3-5 peers or small sellers. Fill this in **during/right after** each session - do not
reconstruct it from memory the night before the deadline.

## Session protocol (same for everyone)
1. (2 min) Explain the goal in two sentences. Do not explain the UI.
2. (6 min) Give them the task: "Find out what customers are unhappy about" using the **Batch Seller Dashboard** with the
   demo CSV (or real reviews). Then one review of their own in the **Single Review Inspector**. Note where they hesitate.
3. (5 min) Ask the three questions below, verbatim.
4. (2 min) Anything else? Thank them.
